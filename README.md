# FARSEA Shopify theme

Online Store 2.0 theme for FARSEA (aesthetic medicine clinic + shop), ENG/ITA.

Connected to Shopify through **Online Store → Themes → Add theme → Connect from GitHub** (branch `main`).
Changes pushed here appear in the connected theme automatically; edits made in the Shopify theme editor are committed back to this repository.

Setup guide (products, custom fields, languages, payments): see `SETUP.md`.
